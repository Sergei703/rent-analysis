# Анализ рынка аренды квартир в Архангельске

## О проекте

Учебный pet-project по анализу рынка долгосрочной аренды квартир в Архангельске.

Цель проекта — пройти полный аналитический pipeline: от самостоятельного сбора данных с сайта недвижимости до подготовки данных, загрузки в PostgreSQL, SQL-анализа, расчёта аналитических метрик, визуализации и формирования выводов.

В рамках проекта сформирован датасет из **125 объявлений** об аренде квартир.

Основные задачи анализа:

* оценить структуру предложения на рынке;
* определить типичный уровень арендной платы;
* сравнить стоимость квартир разных типов;
* исследовать стоимость аренды за 1 м²;
* изучить различия между этажами и типами домов;
* сегментировать объявления по стоимости;
* подготовить данные для дальнейшего продуктового и бизнес-анализа.

Основной результат проекта — аналитический набор метрик и выводов, демонстрирующий применение **Python, Pandas, PostgreSQL и SQL** на реальном наборе данных, полученном программным способом.

## Источник данных

Данные собраны с сайта **Яндекс Недвижимость** со страницы объявлений долгосрочной аренды квартир в Архангельске.

В отличие от анализа готового датасета, данные были получены самостоятельно с помощью Python-парсера на основе:

* `Requests` — получение HTML-страниц;
* `BeautifulSoup` — извлечение необходимых полей из HTML.

Собранные объявления были сохранены в формате CSV и далее использованы для подготовки данных и загрузки в PostgreSQL.

### Собираемые данные

Для каждого объявления извлекались:

* идентификатор объявления;
* URL;
* количество комнат;
* стоимость аренды;
* размер залога;
* координаты;
* общая, жилая площадь и площадь кухни;
* этаж и этажность дома;
* год постройки;
* высота потолков.

### Ограничения сбора

Датасет отражает состояние предложений на момент парсинга. Количество объявлений и их характеристики могут изменяться со временем: новые объявления появляются, существующие снимаются с публикации, а данные в карточках могут обновляться.

Кроме того, часть характеристик объявлений отсутствует непосредственно в исходных данных.

## SQL-анализ

SQL является основной частью аналитического этапа проекта. Запросы использовались не только для получения базовых статистик, но и для сравнения сегментов, ранжирования объявлений и расчёта относительных показателей.

### Базовые метрики

Рассчитаны:

* количество объявлений;
* средняя стоимость аренды;
* медианная стоимость аренды;
* средняя стоимость 1 м²;
* доля объявлений без залога.

Для расчёта медианы использовался процентиль:

```sql
SELECT
    PERCENTILE_CONT(0.5)
        WITHIN GROUP (ORDER BY price_month) AS median_price
FROM rent_offers;
```

`PERCENTILE_CONT()` позволяет использовать медиану как более устойчивую к выбросам характеристику центрального уровня цен.

### Анализ по количеству комнат

Рынок разделён на категории по количеству комнат:

* студии;
* 1-комнатные;
* 2-комнатные;
* 3-комнатные;
* 4-комнатные квартиры.

Для сравнения сегментов рассчитывались количество объявлений, средняя стоимость аренды и стоимость 1 м².

Оконная функция позволяет сравнить каждое объявление со средним значением соответствующего сегмента:

```sql
SELECT
    offer_id,
    rooms,
    price_month,
    price_month / area_total AS price_m2,
    AVG(price_month / area_total)
        OVER (PARTITION BY rooms) AS avg_price_m2_by_rooms
FROM rent_offers;
```

`PARTITION BY rooms` позволяет рассчитывать показатель отдельно для каждого типа квартиры, не теряя детализацию отдельных объявлений.

### Анализ этажности

Квартиры разделены на три категории:

* первый этаж;
* последний этаж;
* средний этаж.

Затем сравнивалась стоимость 1 м² между сегментами.

Такой анализ позволяет проверить гипотезу о том, влияет ли расположение квартиры внутри дома на её стоимость.

### Анализ года постройки

Дома сегментировались по периоду строительства:

* Historical;
* Soviet;
* Post-Soviet;
* Modern.

Для сегментов сравнивались показатели стоимости аренды и стоимости 1 м².

Такой подход позволяет перейти от отдельных значений `building_year` к более интерпретируемым группам объектов недвижимости.

### Сегментация рынка по стоимости

Для распределения объявлений по ценовым сегментам применялся `NTILE()`.

```sql
SELECT
    offer_id,
    price_month / area_total AS price_m2,
    NTILE(4) OVER (
        ORDER BY price_month / area_total
    ) AS price_segment
FROM rent_offers;
```

`NTILE(4)` разделяет объявления на четыре группы примерно одинакового размера по стоимости 1 м².

Это позволяет анализировать не только среднюю цену рынка, но и относительное положение каждого объявления внутри выборки.

### Ранжирование объявлений

Для ранжирования объектов по стоимости использовалась оконная функция `DENSE_RANK()`.

```sql
SELECT
    offer_id,
    rooms,
    price_month,
    DENSE_RANK() OVER (
        ORDER BY price_month DESC
    ) AS price_rank
FROM rent_offers;
```

Такой подход позволяет определить позиции объявлений в ценовом распределении без потери исходных строк.

### CTE

CTE (`WITH`) использовались для разделения сложной аналитической задачи на последовательные этапы.

Например:

```sql
WITH offers AS (
    SELECT
        offer_id,
        rooms,
        price_month,
        price_month / area_total AS price_m2
    FROM rent_offers
)
SELECT
    rooms,
    COUNT(*) AS offers_count,
    ROUND(AVG(price_m2), 2) AS avg_price_m2
FROM offers
GROUP BY rooms
ORDER BY rooms;
```

Такой подход делает SQL-код более читаемым и позволяет повторно использовать результаты промежуточных расчётов.

## Основные результаты

1. **Основу выборки формируют 1- и 2-комнатные квартиры** — по 47 объявлений каждой категории. На эти два сегмента приходится основная часть собранного предложения.

2. **Медианная стоимость аренды составляет 26 000 ₽ в месяц.** Медиана выбрана как одна из ключевых характеристик уровня цен, поскольку она менее чувствительна к отдельным дорогим предложениям.

3. **Средняя стоимость аренды 1 м² составляет 695,35 ₽.** Этот показатель позволяет сравнивать квартиры разной площади более корректно, чем абсолютная стоимость аренды.

4. **39% объявлений имеют нулевой размер залога.** Это является заметной особенностью структуры предложений в собранной выборке и может быть использовано для отдельного анализа условий аренды.

5. **Распределение предложения по комнатам неоднородно.** В выборке присутствуют 17 студий, 47 однокомнатных, 47 двухкомнатных, 12 трёхкомнатных и только 2 четырёхкомнатные квартиры.

6. **Сегментация по стоимости 1 м² позволяет сравнивать объявления относительно друг друга**, а не только относительно среднего значения рынка. Для этого применялся `NTILE(4)`.

7. **Анализ этажей позволяет отдельно сравнить первый, последний и средние этажи**, что создаёт основу для проверки гипотезы о влиянии расположения квартиры на стоимость.

8. **Анализ года постройки позволяет исследовать различия между возрастными сегментами жилья**, не ограничиваясь сравнением отдельных годов.

> Выводы относятся к собранной выборке из 125 объявлений и не являются оценкой всего рынка долгосрочной аренды Архангельска.

## Ограничения проекта

Результаты необходимо интерпретировать с учётом ограничений исходных данных.

* Размер выборки — **125 объявлений**, поэтому она не позволяет делать статистически надёжные выводы обо всём рынке Архангельска.
* Данные отражают состояние рынка **на момент сбора**.
* Объявления могут быть сняты с публикации или изменены после парсинга.
* Часть характеристик содержит пропуски.
* Качество и полнота информации зависят от данных, указанных в объявлениях.
* Некоторые признаки нельзя напрямую интерпретировать без дополнительной проверки их семантики.
* Средние значения и сегментация чувствительны к структуре конкретной выборки.
* Пространственный анализ основан на координатах объявлений и не учитывает все факторы, влияющие на привлекательность конкретной локации.
* Полученные результаты следует рассматривать как **исследование собранной выборки**, а не как официальную статистику рынка аренды Архангельска.

**2. Уровень арендной платы**

Медианная стоимость аренды составляет **26 000 ₽ в месяц**, что позволяет использовать эту величину как ориентир типичного предложения в исследуемой выборке.

**3. Цена относительно площади**

Средняя стоимость аренды составляет **695,35 ₽/м²**. Метрика позволяет корректнее сравнивать квартиры разной площади и использовать стоимость 1 м² как основу для сегментации.

**4. Условия входа в аренду**

В **39% объявлений** отсутствует залог (`deposit = 0`). Это заметная характеристика предложения, которую можно использовать при дальнейшем исследовании доступности квартир для арендатора.

**5. Структура предложения**

В выборке представлены преимущественно квартиры массового сегмента: студии, 1- и 2-комнатные квартиры составляют основную часть наблюдений, тогда как 4-комнатные квартиры представлены всего двумя объявлениями.

**6. Возможность сегментации рынка**

Использование `NTILE()` позволяет разделить объявления на относительные ценовые сегменты и анализировать рынок не только через средние значения, но и через положение конкретного объекта внутри распределения.

**7. Возможные направления дальнейшего анализа**

На следующем этапе проект можно расширить за счёт:

* сбора данных за несколько временных периодов;
* анализа динамики стоимости аренды;
* географического сравнения районов;
* расчёта более детальных ценовых сегментов;
* сравнения стоимости аренды с площадью и характеристиками дома;
* построения интерактивного дашборда;
* добавления данных о транспортной доступности и инфраструктуре.

Основной аналитический pipeline:

```text
Python
  ↓
Web Parsing
  ↓
Data Cleaning
  ↓
Data Quality Check
  ↓
PostgreSQL
  ↓
SQL Analytics
  ↓
Metrics & Segmentation
  ↓
Visualization
  ↓
Analytical Insights
```

Проект демонстрирует практическое применение **Python, Pandas, PostgreSQL и SQL** для решения аналитической задачи — от получения исходных данных до формирования выводов на их основе.
